# M4 计划（不含写作 / 草稿 / 导出）

> 日期：2026-10-28
> 前置：M3 已通过真机验收（`docs/M3_REPORT.md`）。
> 原则：逻辑以 nextest + 桌面端验证为主；平台能力集中在 M4 末做一次真机门禁。

## 范围

明确**不做**：写回答/文章/想法、草稿箱、Markdown 编辑器、导出 PDF/Markdown/HTML、图片上传。

### A. 内容与交互

1. 评论回复与分页（任务 #9）
   - 根评论 offset 分页 + “加载更多”。
   - 解析 `child_comments`，嵌套展示子评论；子评论分页后续。
2. 完整搜索（任务 #11）
   - 签名 `search_v3`，类型/排序筛选、分页。
   - 搜索结果 → 回答/文章详情。
3. 通知分页与已读状态（并入 #6 后续）。

### B. 个性化与本地能力

4. 用户 / 话题屏蔽（任务 #12）
   - 复用 SQLite 表；按作者/话题过滤 feed/hot/daily。
   - “我的 → 屏蔽”统一管理关键词、用户、话题。
5. 阅读与外观设置（任务 #13）
   - 字号、行高、段距、深浅色、默认 Tab 持久化。
6. 图片磁盘缓存与失败占位（任务 #14）
   - 内存 + 磁盘 LRU，弱网骨架，失败占位。

### C. 平台能力（真机门禁）

7. 视频播放（任务 #15）
   - Android：Media3/ExoPlayer 覆盖层或 gpui-mobile video_player 桥。
   - 桌面：mpv/gstreamer 或外部播放器兜底。
8. TTS 朗读（任务 #16）
   - Android TextToSpeech；桌面系统 TTS。
9. 扫码 / 手机号登录（任务 #17）
   - QR 获取/轮询；手机验证码 + 风控提示。
10. 深链与分享（后置）

### D. 门禁

11. M4 平台门禁（任务 #18）
    - 真机：视频、TTS、扫码/手机登录、图片缓存、深链 + M3 回归。
    - 桌面：`cargo nextest`、clippy、桌面截图。

## 实施顺序

1. 评论分页/子评论（纯逻辑 + UI，可单测）。
2. 搜索 `search_v3`（可先用录制 fixture 单测）。
3. 用户/话题屏蔽 + 设置持久化。
4. 阅读设置 + 图片缓存。
5. 视频 / TTS / 登录（平台门禁集中验证）。
6. M4 门禁 + 报告。

## 风险

| 风险 | 应对 |
| --- | --- |
| `search_v3` 参数/风控变化 | 失败时回退到搜索建议；集中参数封装 |
| 子评论接口未公开字段 | 先渲染根评论内嵌 `child_comments`，缺失时显示“查看 N 条回复” |
| 视频/TTS 桥接不完整 | 先做 Android 原生播放器/系统 TTS 兜底，桌面外链 |
| 登录风控/验证码 | Cookie 导入始终可用；扫码/手机登录作为增强 |
