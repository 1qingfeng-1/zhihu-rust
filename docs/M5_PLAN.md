# M5 计划（差异化与发布）

> 日期：2026-10-28
> 前置：M4 功能完成（`docs/M4_REPORT.md`），真机 UI/平台门禁按要求顺延到本阶段。
> 状态：桌面双栏/快捷键、崩溃报告、诊断、发布流水线已完成；
> 真机门禁待设备接入。进展见 `docs/M5_REPORT.md`。
> 原则：先补 M4 门禁债，再做桌面体验、可靠性与发布；本地推荐 / NLP 过滤按 P2 单独评估。

## 范围

### A. M4 门禁补齐（需设备）

1. Android 真机门禁（任务 #18）
   - 视频播放/释放、TTS、扫码登录、手机号登录（真实号码）、深链冷启动/热启动。
   - M3 回归：滑动切 Tab、输入法、详情互动、通知、屏蔽、后台恢复。
   - 验收产物：截图 / logcat / 门禁记录写入 `docs/M5_REPORT.md`。

### B. 桌面端体验

2. 自适应双栏布局（任务 #23）
   - 宽窗口（≥900px）左侧导航栏 + 右侧内容区；窄窗口保持移动端单栏。
   - 侧栏包含品牌、搜索、5 个 Tab、消息 / 历史 / 屏蔽入口、登录态与主题。
   - 详情 / 搜索 / 评论 / 通知等路由页同样在侧栏壳内渲染。
3. 键盘快捷键（任务 #24）
   - `Ctrl/Cmd+K` 或 `Ctrl+F` 聚焦搜索，`Ctrl+1..5` 切 Tab，
     `Ctrl+R` 刷新当前视图，`Ctrl+D` 切换主题，`Esc` / `Alt+←` 返回。
   - 侧栏显示快捷键提示；输入框聚焦时不触发单键导航。
4. 无障碍基础
   - 侧栏、底部导航、Feed 卡片提供 `aria_label` / `aria_selected`；
     可点击区域 ≥38px。
   - GPUI 无障碍树仍在演进，完整屏幕阅读器支持作为后续改进。

### C. 可靠性与诊断

4. 本地崩溃报告（任务 #25）
   - panic hook 写入 `data_dir/crashes/crash-<timestamp>.log`（含版本、线程、消息、回溯）。
   - 保留最近 20 份；“我的 → 崩溃日志”查看/清空，不上传。
5. 性能与运行诊断
   - 记录启动耗时、首次内容加载耗时、图片缓存体积、崩溃数。
   - “我的 → 诊断”面板展示；`ZHIHU_PERF=1` 时在状态栏显示耗时。

### D. 发布

6. 发布流水线与签名（任务 #26）
   - Android release：`keystore.properties` / 环境变量注入签名，`assembleRelease`。
   - 桌面 release：Windows/Linux 构建产物（zip）。
   - GitHub Actions：tag 触发 APK + 桌面包，附 changelog；CI 保留 fmt/clippy/nextest。
   - 商店素材：应用图标、截图、隐私说明（无遥测、本地存储说明）。

### E. P2 评估（不在本阶段强制交付）

7. 本地推荐 / 混合推荐（已落地可选模式）
   - 参考项目 `FeedRecommend` 权重、爬虫与样本采集；需要单独的隐私/合规评估。
   - 已实现 `zhihu-recommend`：主题/作者亲和度 + 标题特征 + 多样性，
     默认关闭，纯本地；完整爬虫/向量推荐不进入近期里程碑。
8. NLP 语义屏蔽（`ort` + tokenizer，可选 feature）
   - 评估模型体积（<10 MB）、离线推理耗时与误杀率；默认关闭，避免包体膨胀。
9. AIGC 标记与投票
   - 依赖服务端接口，暂不实现；保留 UI 字段位。

## 实施顺序

1. M4 真机门禁（设备接入后第一优先级）。
2. 桌面双栏 + 快捷键（纯桌面，可立即验证）。
3. 崩溃报告 + 诊断面板。
4. 发布流水线 / 签名 / 商店素材。
5. P2 评估文档，按结论决定后续里程碑。

## 风险

| 风险 | 应对 |
| --- | --- |
| `gpui-mobile` 真机行为与桌面不一致 | 双栏布局按平台 cfg 隔离，移动端保持现有路径 |
| 侧栏复用移动端组件导致状态重复（搜索框） | 宽窄布局互斥渲染，同一 `InputState` 只挂载一次 |
| 崩溃日志含隐私内容 | 只写 panic 消息/回溯，不写 Cookie、请求体；本地保留并可一键清空 |
| release 签名密钥泄漏 | 仅从环境变量/未跟踪的 `keystore.properties` 读取，文档说明 |
| 本地推荐 / NLP 包体与合规 | 默认关闭、独立 feature；先评估后实现 |
